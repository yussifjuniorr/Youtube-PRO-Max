# Cinema YouTube (Android APK)

This Android project turns your **Cinema Style for YouTube v3.2** extension into an installable Android APK with Google Sign-In support and automatic GitHub Actions builds.

## How to get your APK
1. Create a new repository on [GitHub](https://github.com/new).
2. Extract this ZIP and upload all files and folders inside it (including `.github`) to your repository.
3. Open the **Actions** tab and wait ~2 minutes for **Build Cinema YouTube APK** to finish.
4. Click the finished run and download **Cinema-YouTube-APK** under **Artifacts**.
5. Extract the downloaded artifact and install `app-debug.apk` on your Android phone.
